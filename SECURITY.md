# Security Policy

## Supported Versions

Users are encouraged to use the latest version of SecureTransac. Below is a list of currently supported versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within SecureTransac, please send an e-mail to ayushalokdubey@gmail.com. All security vulnerabilities will be promptly addressed.

Please include the following information in your report:

* Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting)
* Full dynamic content or screenshots if possible
* Any additional info that might be useful
